# 智能语音识别系统

基于腾讯云ASR的实时语音识别应用，支持流式识别、语音指令、热词优化和成本控制。

## 功能特性

### 核心识别
- **实时语音识别**：支持流式模式和普通模式
- **静音自动提交**：检测到2秒以上静音自动触发识别
- **音频能量可视化**：实时显示麦克风输入能量
- **环境噪音自适应**：自动校准噪音阈值，减少误触发

### 语音指令
- `句号` / `句点` → 插入 `。`
- `换行` / `另起一行` → 插入换行
- `删除` / `删除最后N个字` → 删除光标前文字
- `清空` → 清空文本框
- `发送` → 触发发送按钮回调

### 纠错机制
- **候选词纠错**：长按/右键点击识别词弹出候选词列表
- **编辑距离算法**：自动生成相似候选词
- **重新说这句**：一键重新录音替换整句

### 成本控制
- **音频长度过滤**：小于500ms音频自动丢弃
- **本地LRU缓存**：最近20条识别结果缓存5分钟
- **置信度过滤**：低质量结果自动过滤
- **三种模式切换**：高精度 / 平衡 / 省流量

### 热词优化
- **场景模式**：会议、医疗、科技、教育、金融
- **自动热词表**：根据场景自动注入热词到ASR引擎

### 网络容灾
- **断网检测**：自动检测网络状态
- **离线队列**：断网时自动保存音频到本地
- **自动重试**：联网后自动处理待识别队列
- **状态提示**：明显UI状态条显示当前状态

## 技术栈

- **后端**：Flask + Flask-SocketIO + 腾讯云ASR SDK
- **前端**：原生JavaScript + Web Audio API
- **实时通信**：Socket.IO

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，填入腾讯云密钥：

```
SECRET_ID=你的SecretId
SECRET_KEY=你的SecretKey
```

### 3. 启动服务

```bash
python app.py
```

或使用启动脚本：

```bash
start.bat
```

### 4. 访问应用

打开浏览器访问 http://localhost:9009

## 使用技巧

1. **流式模式**：适合长对话，实时显示识别结果
2. **普通模式**：适合短句，等待静音后自动提交
3. **场景切换**：根据谈话内容选择对应场景提升识别准确率
4. **省流量模式**：网络不佳时减少API调用
5. **纠错**：识别错误时右键点击词汇选择正确候选词

## API接口

### POST /api/recognize

识别音频数据

**请求体 (JSON)**:
```json
{
  "audio": "base64编码的音频数据",
  "format": "webm",
  "hotwords": "热词1,热词2"
}
```

**响应**:
```json
{
  "success": true,
  "original": "原始识别文本",
  "processed": "处理后文本"
}
```

### POST /api/type

输入文字到系统

**请求体**:
```json
{
  "text": "要输入的文字"
}
```

## 注意事项

1. 首次使用需要配置腾讯云ASR密钥
2. 腾讯云ASR按调用量计费，请关注用量
3. 浏览器需要允许麦克风权限
4. 推荐使用Chrome或Firefox浏览器
5. 热词功能需要腾讯云控制台开启相关服务
